# Personal Knowledge Base Website

## About the Project
The Personal Knowledge Base Website is a web-based application designed to help users create, organize, store, and manage their personal notes in one place. It provides a simple and user-friendly interface for managing information efficiently.

## Features
- Create and manage personal notes.
- Organize notes using categories and tags.
- Add custom categories.
- View all notes in one place.
- Display recently added notes.
- Simple and attractive user interface.
- Responsive design for different screen sizes.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
personal-knowledge-base/
│
├── index.html
├── style.css
├── script.js
└── images/
```

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Start creating and organizing your notes.

## Purpose
This project was developed to improve practical knowledge of frontend web development, JavaScript functionality, and user interface design.
